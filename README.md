# 4.Java-opps
Java OOP Concepts
📌 About This Repository

This repository contains Java programs demonstrating Object-Oriented Programming (OOP) concepts, from basic principles to advanced topics. It is intended for learning, practicing, and understanding OOP in Java through simple examples.

🎯 Objectives
Understand the fundamentals of Object-Oriented Programming.
Learn how to implement OOP concepts using Java.
Practice writing reusable, modular, and maintainable code.
Build a collection of Java programs for learning and revision.

📚 OOP Concepts Covered
1. Classes and Objects
Defining classes and creating objects.
Instance variables and methods.
Constructors and constructor overloading.

3. Encapsulation
Data hiding using access modifiers.
Getters and setters.
Private variables and controlled access to data.

4. Inheritance
Single inheritance.
Multilevel inheritance.
Hierarchical inheritance.
Using the super keyword.
Method overriding.

5. Polymorphism
Compile-time polymorphism (method overloading).
Runtime polymorphism (method overriding).
Dynamic method dispatch.

6. Abstraction
Abstract classes and abstract methods.
Interfaces.
Implementing abstraction in Java.

🔑 Additional Java Concepts
this and super keywords.
Static variables, methods, and blocks.
Final variables, methods, and classes.
Access modifiers: private, default, protected, and public.
Association, aggregation, and composition.
Interfaces and multiple inheritance through interfaces.
Object class methods such as toString(), equals(), and hashCode().
Packages and imports.

▶️ How to Run
Clone or download this repository.
Install the Java Development Kit (JDK).
Open a Java source file in your IDE or terminal.
Compile the program:
bash
javac FileName.java

Run the program:
bash
java ClassName


Replace FileName and ClassName with the actual Java file name and class name.
